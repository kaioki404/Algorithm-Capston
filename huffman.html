Huffman file compressor

Type or open a text file. The page counts how often each byte appears, builds the Huffman tree, gives frequent bytes short codes, encodes the text, then decodes it again to prove nothing was lost.

Huffman tree

Left edge is 0, right edge is 1. Leaves show the byte and its count; round nodes show the combined count.

Codes

Encoded bits (first 400)








Complexity


n is the number of input bytes; k is the number of distinct bytes (k ≤ 256).




StageTimeSpace


Count frequenciesO(n)O(k)


Build tree with a min-heapO(k log k)O(k)


Generate codes (tree walk)O(k)O(k)


EncodeO(n)O(n) output bits


DecodeO(n)O(n) output bytes


Whole pipelineO(n + k log k)O(n + k)




Because k never exceeds 256, the tree-building step is effectively constant and the pipeline grows linearly with file size.
